## How to Use GSC Data

### 1. Find Underperforming Pages
- Go to **GSC > Performance > Queries**
- Filter for high impressions, low CTR
- Update title/meta description to improve CTR

**Example:**
| Keyword | Impressions | Clicks | CTR |
|---------|---|---|---|
| interior design services bangalore | 45 | 2 | 4.4% |

**Action:** Title might be unclear. Improve to: "Luxury Interior Design Services in Bangalore — Free Consultation"

### 2. Identify Ranking Opportunities
- Go to **GSC > Performance > Queries**
- Filter for position 11–30 (shows keywords you're close to ranking for)
- Create new content or expand existing pages for those queries

### 3. Monitor Core Web Vitals
- Go to **GSC > Core Web Vitals**
- Track: LCP, FID, CLS over time
- Target: All green (good) for mobile and desktop
